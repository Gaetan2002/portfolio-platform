# Progress

- This folder contains one summary file per completed phase of the project.
- Each file is written at the end of its phase.
- Files are named `phase-<number>-<name>.md`, for example, `phase-0-analysis.md`.
- Each summary must contain what was done, the decisions made and what I have learned.
- `PROJECT_STATUS.md` contains a global summary of the project, whereas the progress folder contains one file per
  phase of the project.
